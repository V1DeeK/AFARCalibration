# Контракт драйвера ПЛАНАР C1220/C2220 / S2VNA

Документ: AFAR-RX-CAL-SW-TZ-01, ред. 1.0 от 29.08.2026, раздел 15, т. 3.1–3.2 (HW-VNA-01…05), т. 6.1, т. 10.3–10.4, т. 11.
Продукт: AFAR RX Calibration Studio, этап 1 и одиночный S21.
Задача: DOC-002.

Это **закрытый** перечень транспорта и SCPI для драйвера `vna-scpi` (волна 9: VNA-002…VNA-005). Команды, которых нет в таблице ниже, в v1 **не посылаются**. Выдуманный SCPI запрещён. Расхождение с установленной S2VNA сначала правит этот файл, затем код.

Код и длинные примеры из руководств сюда не копируются.

## 2. Транспорт

Основной канал: **TCP/IP Socket** (т. 3.1). HiSLIP в РЭ описан на той же стр. 1111; в v1 драйвера его нет.

| Параметр | Правило |
|----------|---------|
| Порт | Пример профиля S2VNA: **5025** (на стр. 1111 также показан 5026). Меню прибора: System → Misc Setup → Network Remote Control Settings → Socket Server/Port. В `run-config.json` поле `vna.port` — **профиль стенда, не константа кода** (т. 6.1). |
| Хост | Только адрес из профиля. Боевые IP стенда в репозиторий не кладутся (т. 10.4). |
| Кадр | Команда и ответ завершаются `<newline>` (`\n`, 0x0A). РЭ ч. 2, стр. 1111. |
| Тайм-аут соединения | По умолчанию **3 с** (HW-VNA-04); значение из конфигурации. |
| Тайм-аут свипа | По умолчанию **30 с** (HW-VNA-04). |
| Повторы | По умолчанию **2** (HW-VNA-04). |
| COM | Последовательный `ScpiComTransport` не является COM/DCOM Automation S2VNA и скрыт из GUI. Рабочий путь — Socket. |
| Запрет | Удалённое выполнение команд ОС отсутствует (т. 10.4). GUI не шлёт SCPI (т. 8.2) — только `measurement-core` через `IVna`. |

## 3. Закрытый набор команд

Краткая форма — как в оглавлении РЭ и в драйвере. Полная форма — из той же статьи РЭ. Суффикс канала `<Ch>` = `{[1]\|2\|…16}`; v1 использует канал по умолчанию (1 / выбранный), без отдельных команд переключения канала.

| Команда | Назначение | Ссылка |
|---------|------------|--------|
| `*IDN?` | Идентификация: изготовитель, модель, серийный номер, версия ПО/аппаратуры. Разрешены C1220 и C2220. | HW-VNA-01; РЭ ч. 2, стр. 1158 (`*IDN?`) |
| `SENS:FREQ:STAR` | Начало свипа, Гц. Полная: `SENSe<Ch>:FREQuency:STARt`. | HW-VNA-02; РЭ ч. 2, стр. 2094 |
| `SENS:FREQ:STOP` | Конец свипа, Гц. Полная: `SENSe<Ch>:FREQuency:STOP`. | HW-VNA-02; РЭ ч. 2, стр. 2096 |
| `SENS:SWE:POIN` | Число точек свипа. Полная: `SENSe<Ch>:SWEep:POINts`. | HW-VNA-02; РЭ ч. 2, стр. 2157 |
| `SENS:BAND` | Полоса ПЧ. Полная: `SENSe<Ch>:BANDwidth[:RESolution]`. Шаг ряда 1 / 1,5 / 2 / 3 / 5 / 7 (стр. 1786 и ТС). | HW-VNA-02; РЭ ч. 2, стр. 1786 |
| `SOUR:POW` | Мощность порта, дБм. Полная: `SOURce<Ch>:POWer[:LEVel][:IMMediate][:AMPLitude]`. | HW-VNA-02; РЭ ч. 2, стр. 2192 |
| `CALC:PAR:DEF S11/S21/S12/S22` | Измеряемый параметр. Полная: `CALCulate<Ch>:PARameter<Tr>:DEFine`. Серия этапа 1 всегда использует **S21**; остальные параметры доступны в ручном одиночном измерении. | HW-VNA-02; РЭ ч. 2, стр. 1479 |
| `FORM:DATA ASC` | Явно выбрать текстовый формат, который разбирает драйвер. | РЭ: `FORMat:DATA ASCii` |
| `TRIG:SOUR BUS` | Перевести анализатор в ожидание программного запуска. | РЭ: `TRIGger:SEQuence:SOURce BUS` |
| `SENS:AVER`, `SENS:AVER:COUN`, `SENS:AVER:CLE`, `TRIG:AVER` | Усреднение соседних развёрток одним программным триггером; фактор 1…999. | РЭ S2VNA 26.x |
| `TRIG:SING` | Одиночный запуск сканирования. Полная: `TRIGger[:SEQuence]:SINGle`. | HW-VNA-02; РЭ ч. 2, стр. 2452 |
| `*OPC?` | Ожидание завершения предыдущей операции (в т.ч. после `TRIG:SING`); ответ `1`. | HW-VNA-02; РЭ ч. 2, стр. 1162 |
| `CALC:DATA:SDAT` | Чтение комплексных отсчётов выбранного трасса (запрос `…:SDATa?`). Длина ответа **2N**: для точки `n` — действительная, затем мнимая часть. | HW-VNA-02; РЭ ч. 2, стр. 1229 |
| `CALC:DATA:XAX?` | Ось X выбранного трасса, N чисел. | HW-VNA-02; РЭ ч. 2, стр. 1235 |
| `SENS:FREQ:DATA?` | Альтернатива оси: массив частот стимула, N чисел. | HW-VNA-02; РЭ ч. 2, стр. 2088 |
| `SYST:ERR?` | Снять очередную ошибку SCPI из FIFO. Полная: `SYSTem:ERRor[:NEXT]?`. Формат: `<код>, <текст>`. Пустая очередь: `0, "No error"`. | HW-VNA-03; РЭ ч. 2, стр. 2359 |
| `SYST:REC:DIR:ACC` | Запрашивается только после `*IDN?` и только для C2220. Для C1220 команда не отправляется. Программа режим не включает. | HW-VNA-05; РЭ ч. 2, стр. 2405 |
| `SENS:CORR:COLL:METH:SOLT2 1,2` | Начать полную двухпортовую SOLT-калибровку для портов 1 и 2. | РЭ S2VNA, полная двухпортовая SOLT |
| `SENS:CORR:COLL:OPEN/SHOR/LOAD <port>` | Измерить открытый канал, КЗ и согласованную нагрузку для указанного порта. | РЭ S2VNA, сбор калибровочных мер |
| `SENS:CORR:COLL:THRU 2,1` | Измерить перемычку между портами 1 и 2. | РЭ S2VNA, полная двухпортовая SOLT |
| `SENS:CORR:COLL:SAVE` | Рассчитать и применить собранные коэффициенты. | РЭ S2VNA, завершение калибровки |

Ось частот после свипа: **либо** `CALC:DATA:XAX?`, **либо** `SENS:FREQ:DATA?`. Выбор фиксируется при сверке с установленной S2VNA; оба мнемоника уже в таблице, третьего источника оси нет.

Рекомендация РЭ и установленный пример `Example4.cpp`: `TRIG:SOUR BUS`, затем `TRIG:SING` + `*OPC?`. Драйвер задаёт BUS явно и не зависит от ручного состояния триггера S2VNA.

## 4. Последовательности (без исходного кода)

Соответствие методам `IVna` из `docs/contracts/cpp-interfaces.md`:

| Шаг | SCPI | Правило |
|-----|------|---------|
| `identify` | `*IDN?` | Сохранить модель, серийный номер, версии; разрешить C1220/C2220. |
| После `identify` C2220 | `SYST:REC:DIR:ACC?` | Если ON без подтверждения — `ERROR`. Для C1220 запрос не посылается. |
| `configure` | Частоты, точки, ПЧ, мощность, выбранный S-параметр, ASCII, BUS-триггер, усреднение | Значения проверены до I/O; серия АФАР принудительно использует S21; `SYST:PRES` не отправляется. |
| `calibrate_two_port` | SOLT2 → OPEN/SHORT/LOAD обоих портов → THRU → SAVE | Каждый шаг выполняется только после подтверждения оператора; используется комплект мер, заранее выбранный в S2VNA. |
| `measure_s21` | `TRIG:SING`, затем `*OPC?`, затем `CALC:DATA:SDAT?` и ось (`XAX?` или `FREQ:DATA?`) | Длина оси = `points`; комплексных пар = `points`. Тайм-аут свипа 30 с, до 2 повторов (HW-VNA-04, AT-07). |
| `drain_errors` | `SYST:ERR?` после **группы** команд, пока не `0, No error` | В событии журнала: исходная команда, код, текст. Уже сохранённые сырые данные не портить (HW-VNA-03). |
| Журнал | — | Двоичные массивы S21 в текст не пишутся. Инженерный профиль: команда, размер ответа, время, контрольная сумма блока (LOG-02). Секреты не писать (LOG-03). |
| `abort` | нет SCPI в этом контракте | `noexcept`: отмена ожидания / закрытие транспорта. Не выдумывать `ABOR`. Не бросать из деструктора. |

## 5. Прямой доступ к приёмникам (HW-VNA-05)

На C2220 есть соединители прямого доступа (страница прибора; ТС, табл. 9.9). Режим меняет схему включения тракта (т. 11 п. 5).

- Пресет S2VNA: **OFF**.
- Драйвер **запрашивает** состояние (`SYST:REC:DIR:ACC?`) при старте серии.
- Если ответ ON / 1 и профиль стенда не подтверждает этот режим явно — отклонить серию.
- Включение (`ON`/`1`) из программы запрещено. Выключение чужого ON без явного профиля тоже не делается «молча»: сначала отказ серии.
- Метод `IVna` для прямого доступа **не добавляется** (см. DOC-003).

## 6. Пределы прибора (проверка конфига, не «сохранность изделия»)

Программа проверяет попадание `run-config` в пределы C2220 **до** SCPI (т. 11 п. 2). Это не гарантия отсутствия повреждения при неверной схеме подключения.

| Параметр | Предел | Источник |
|----------|--------|----------|
| Частота | 100 кГц…20 ГГц (на странице прибора: 0,1 МГц–20 ГГц) | ТС, общие сведения / табл. 5.1; страница C2220 |
| Мощность порта | −60…+10 дБм | ТС, табл. 5.1; страница C2220 |
| Точки свипа | 2…500 001 | ТС, табл. 5.1 / 9.1; РЭ стр. 2157 (нижняя граница 2) |
| ПЧ C2220 | 1 Гц…1 МГц, ряд 1 / 1,5 / 2 / 3 / 5 / 7 | ТС (C1220, C2220); РЭ стр. 1786 |
| S-параметр серии этапа 1 | только S21; ручной экран дополнительно S11/S12/S22 | т. 6.1, HW-VNA-02 |

**Динамический диапазон не порог ПО.** Страница C2220: 145 дБ тип. ТС, табл. 1.2 для C2220/C2420: ТХ **135 дБ** (1 МГц–20 ГГц, ПЧ 10 Гц); ниже 1 МГц в той же таблице ТХ 110 дБ. Ни 145, ни 135 не используются как допуск QC, LUT или отбраковка серии.

## 7. Что сознательно отсутствует

Нет в v1: HiSLIP, `INIT`, `ABOR`, пресеты, автоматическое создание калибровки, бинарные форматы блока и команды вне таблицы § 3.

Признак `overload` в `ComplexSweep` (DOC-003) не имеет SCPI в этом контракте: его нельзя заполнять выдуманной командой.

## 8. Сверка перед кодом драйвера (волна 9)

До `C2220Vna` / `ScpiSocketTransport`:

1. Сверить синтаксис таблицы § 3 с Help установленной S2VNA на стенде.
2. При расхождении — править **этот** контракт, затем код.
3. Не включать прямой доступ.
4. Прогнать AT-01 на имитаторе `*IDN?`; на живом C1220/C2220 — когда прибор доступен.

Порт 5025 в примерах S2VNA и ТЗ — иллюстрация профиля, не литерал в исходниках.
