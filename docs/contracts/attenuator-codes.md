# Контракт примера `attenuator-codes.csv`

Документ: AFAR-RX-CAL-SW-TZ-01, ред. 1.0 от 29.08.2026, т. 6.2.
Продукт: AFAR RX Calibration Studio, этап 1.
Задача: DATA-002.

Это контракт примера таблицы кодов аттенюатора. Канонические имена колонок заданы в `docs/contracts/data-formats.md` (раздел 6). Разбор файла в коде — задача DATA-004; этот документ исходный код не описывает.

## 1. Назначение

Файл `examples/attenuator-codes.csv` — **пример** входной таблицы по т. 6.2. Он не является утверждённой заказчиком таблицей изделия (т. 14 ТЗ). Боевая таблица стенда в репозиторий не кладётся.

Кодировка: UTF-8 без BOM. Концы строк: LF (`\n`). Имя файла — ASCII, дефис ASCII.

## 2. Заголовок и колонки

Заголовок строго:

```
att_code,att_cmd_db,enabled,settle_ms
```

| Колонка | Правило в примере |
|---------|-------------------|
| `att_code` | целые 0…63, **64 уникальных** значения, по одному на строку |
| `att_cmd_db` | номинальная подпись вида `0.00`, `0.50`, …, `31.50` (шаг 0,5 дБ **как в примере ТЗ**) |
| `enabled` | `true` для всех строк примера |
| `settle_ms` | `20` для кодов 0…62; для кода **63** — `30`, как в примере ТЗ |

`N_A` для этого примера равно 64: все строки с `enabled=true`. Ось `/axes/att_code` в серии, построенной на этом файле, имеет длину 64.

## 3. Запрет физической и линейной интерпретации

Программа не считает код 0 равным 0 дБ и не считает зависимость линейной. Поле `att_cmd_db` только подпись и начальное приближение.

Следствия для любой реализации (в том числе DATA-004):

- Код `0` **не** означает физические 0 дБ на изделии.
- Арифметический ряд `att_code * 0.5` в примере ТЗ **не** модель аттенюатора и **не** измерение.
- `att_cmd_db` не подменяет измеренное ослабление и не участвует в выборе кодов как факт измерения.
- Зависимость кода от децибел не предполагается монотонной и из этого CSV не интерполируется.

## 4. Построковая выдержка

`settle_ms` задаётся **на строку** и может отличаться от `timing.settle_ms` в `run-config.json`. В примере ТЗ код 63 получает 30 мс, остальные — 20 мс. Разборщик читает выдержку из строки, а не подставляет константу программы.

## 5. Что этим примером не закрывается

- Утверждённая таблица заказчика и протокол контроллера (т. 14).
- Разбор и валидация CSV в коде (DATA-004).
