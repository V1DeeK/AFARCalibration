# Руководство администратора

## Установка

Распакуйте переносимый архив в локальный каталог с правом записи. Установка Qt,
MinGW или Visual C++ Runtime не требуется: используемые DLL входят в комплект.
Не запускайте программу непосредственно из ZIP или сетевого каталога.

Поддерживаемая цель этапа 1: Windows 10/11 x64. Для работы с прибором разрешите
исходящее TCP-соединение к локальному S2VNA; входящий порт приложению не нужен.

## Каталоги и права

- Исполняемые файлы держите в каталоге только для чтения для обычных операторов.
- Каталог серий должен допускать создание, переименование и синхронную запись файлов.
- Не храните пароли и персональные данные в JSON-профилях.
- Архивируйте весь каталог серии вместе с `manifest.sha256`.

## Проверка поставки

Сверьте SHA‑256 ZIP с соседним файлом `.sha256`, затем распакуйте архив и запустите:

```powershell
powershell -ExecutionPolicy Bypass -File tools\verify-series.ps1 -SelfTest
```

SBOM находится в `SBOM.spdx.json`, сведения о лицензиях — в
`THIRD_PARTY_NOTICES.md` и `licenses/`.

Сценарий установщика находится в `packaging/windows-installer.iss`. Если Inno Setup
доступен как `iscc.exe`, `tools/package-windows.ps1` дополнительно создаёт setup EXE.
Подписание выполняется только сертификатом владельца поставки; тестового сертификата
в проекте нет.

## Диагностика

1. Проверьте свободное место и права каталога данных.
2. Проверьте `run-events.jsonl` и его ротированные сегменты.
3. Выполните `verify-series.ps1` для закрытой серии.
4. Для S2VNA используйте `docs/S2VNA-setup.md`.
5. Не удаляйте частичную серию: передайте её разработчику вместе с профилем и логами.

## 24‑часовой программный прогон

```powershell
$env:AFAR_RUN_AT12='1'
.\tests\test_at12_soak.exe
```

По умолчанию длительность — 86400 секунд, стабилизация — 3600 секунд. Для короткой
проверки задайте `AFAR_AT12_SECONDS` и `AFAR_AT12_STABILIZE_SECONDS`. CSV сохраняется
в `%TEMP%\afar_at12_soak\at12-soak.csv`. Критерий: рост RSS после стабилизации не
более 10%.

## Ограничения до ввода стенда

Не считаются подтверждёнными без заказчика и оборудования: протокол и safe-state
контроллера АФАР, калибровка и SCPI-поведение конкретной версии S2VNA/C2220,
метрологические пороги, утверждённая таблица кодов и испытания реальных каналов.
