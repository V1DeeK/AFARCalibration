# Руководство оператора AFAR RX Calibration Studio

## 1. Назначение

Программа выполняет автоматизированный съём S‑параметров каналов АФАР, контроль
качества, расчёт прямой и обратной LUT и формирование протоколов. До подключения
реального стенда используйте только режим симуляции.

## 2. Подготовка серии

1. Запустите `AfarRxCalibrationStudio.exe`.
2. Выберите профиль `run-config.json` и таблицу `attenuator-codes.csv`.
3. Проверьте идентификатор серии, диапазон каналов, частотную сетку и каталог данных.
4. В режиме прибора убедитесь, что S2VNA уже запущен и адрес/порт совпадают с профилем.
5. Нажмите «Старт» только после подтверждения безопасного состояния изделия.

Пример профиля находится в `examples/run-config.example.json`. Адреса и COM-порт
в примере не являются настройками реального стенда.

### Встроенные графики S2VNA

На вкладке «Измерение S-параметров» отображается только область графиков S2VNA:
после подключения C2220 она встраивается автоматически, а кнопка «Показать график
S2VNA» позволяет повторить подключение окна. Для проверки интерфейса подходит и
вручную запущенная S2VNA с Socket-сервером, включая Demo Mode. Кнопки S11/S21/S12/S22
и КСВН-1/КСВН-2 справа задают показываемые трассы именно в S2VNA. «Отдельно/Вместе»
меняет компоновку её графиков, «Формат отображения» — формат S-трасс, а «Показать весь
диапазон» выполняет автомасштабирование. S2VNA непрерывно обновляет графики сама:
кнопки «Построить графики» больше нет.

«Добавить маркер» создаёт маркер на всех отображаемых трассах. Его можно передвинуть
в самом графике S2VNA; после перемещения нажмите «Обновить значения», чтобы обновить
терминал и калькулятор. «Снять измерение для отчёта» отдельно получает полный набор
S11/S21/S12/S22 и открывает возможность сохранить `.s2p` и PDF; она не включает
постоянную отрисовку в Studio.

Чтобы восстановить четыре графика из состояния, нажмите «Загрузить состояние
S2VNA (.sta)», выберите `examples/s2vna/21102026.sta` либо свой файл и подтвердите
восстановление. Файл-образец содержит диапазон 4,9–6,0 ГГц, 5501 точку и
калибровочные данные от 21.10.2026. Загрузка меняет настройки, может включить
ВЧ-выход и заменить действующую калибровку. Перед загрузкой Studio сохраняет
временную полную копию прежнего состояния S2VNA. Кнопка «Откатить загрузку состояния»
возвращает его без перезапуска; доступен один откат последней загрузки до закрытия
программы или отключения VNA. После загрузки Studio считывает из S2VNA частоты,
точки, ПЧ, мощность, усреднение, ВЧ-выход, коррекцию, трассы и маркеры.

Частоты, точки, ПЧ, мощность и усреднение можно изменить в «Настройке частоты»;
для передачи изменений в прибор нажмите «Применить параметры к S2VNA». ВЧ-выход
и коррекция управляются отдельной кнопкой «Применить ВЧ и коррекцию». Изменение
диапазона или числа точек может повлиять на применимость коррекции — проверьте
её перед измерением. Калибровочные коэффициенты вручную не редактируются.
Восстановление состояния не запускается автоматически.

## 3. Во время измерения

- «Пауза» завершает текущую атомарную операцию и останавливает переход к следующей.
- «Продолжить» возобновляет незавершённую серию без перезаписи подтверждённых слотов.
- «Аварийный стоп» прекращает серию. Физическое безопасное состояние контроллера
  должно быть подтверждено владельцем протокола изделия.
- Ошибки связи, перегрузка и повторные попытки отражаются в журнале серии.

Не редактируйте файлы каталога серии во время работы.

## 4. Результат

Успешно завершённая серия содержит конфигурацию, исходные S21, CSV, LUT, JSONL-журнал,
PDF-протоколы и `manifest.sha256`. Выполните независимую проверку:

```powershell
powershell -ExecutionPolicy Bypass -File tools\verify-series.ps1 `
  "C:\Data\RX16-YYYYMMDD-NNN"
```

Результат `PASS` означает совпадение SHA‑256, наличие всех файлов и корректность
базовой структуры. Это не заменяет метрологическое заключение.

Для каждого измеренного канала откройте `channel-XX-report.pdf`. На пяти страницах
приведены сводка, покрытие 64×64, карты ослабления и фазовой ошибки на центральной
частоте и до 20 худших состояний. `PASS` возможен только при завершённых и пригодных
4096 из 4096 состояний. Отчёты деморежима имеют красную отметку
«DEMO — НЕ МЕТРОЛОГИЯ» и не должны использоваться как метрологический результат.

Рядом с рабочим `channel-XX-calibration.parquet` создаётся
`channel-XX-calibration.csv`. Его можно открыть обычным текстовым редактором или
табличной программой; десятичный разделитель всегда точка. Совпадение CSV с рабочей
LUT проверяется программой до завершения серии, а SHA-256 обоих файлов указан в PDF
и `manifest.sha256`. CSV не является файлом контроллера изделия.

## 5. Восстановление

После перезапуска выберите тот же каталог и профиль. Программа определит завершённые
слоты и предложит продолжение. Перед продолжением проверьте подключение, калибровку
ВАЦ и состояние изделия. Сохраните исходный каталог серии до любых ручных действий.

## 6. AT‑12

Вкладка приёмочных испытаний пишет телеметрию процесса в CSV. Запуск и остановка
24‑часового прогона выполняются оператором; после перезапуска приложения активный
прогон восстанавливается автоматически.

## 7. Связь с платой (PS)

1. Вкладка **«Настройки»**, окошко «Подключение к плате»: введите IP платы и её MAC, порты TCP 49600 и
   UDP 49601 → **«Подключиться»**. IP у платы меняется, MAC — нет: если по
   адресу плата не ответила, программа сама ищет её по MAC в локальной сети и
   подставляет найденный адрес. **«Найти по MAC»** ищет сразу. Пока оператор
   не нажал **«Отключиться»**, программа при следующем запуске подключится
   сама.
2. **«Журнал»** справа: на вкладке «Журнал обмена» — счётчики (TCP
   отправлено и принято, UDP принято и отброшено, сообщения), весь обмен
   таблицей и кнопка «Очистить журнал»; на вкладке **«Одиночное сообщение»** —
   любая команда PS с payload, история и пакеты «Отправлено / Получено», а
   также период keep_alive в миллисекундах (200–60000, по умолчанию 5000).
   Отказы PS (например `HW_NOT_READY` у модуля, который не ответил по RS-485)
   и неисправности из UDP-пакета технического состояния видны красным в
   «Тех. состоянии» на вкладке **«Ошибки»**.
3. **«Полное сканирование»** (вкладка «Настройки», под «Модулями»): частоты, сектор, период → **«Старт»**. Изделие
   само переводится в режим полного сканирования; результаты приходят по одной
   частоте.
4. Там же, в «Режиме изделия»: **«Перейти в сервисный»**, затем АЦП,
   луч и модули (**«Записать»** уходят только поля с отметкой «Передать»).
5. Вкладка **«Тестовый прогон»** — стресс-тест TCP («отправить N команд за
   T мс / секунд / минут», в списке все команды протокола, команды-установки
   по умолчанию не отмечены и при отметке дают предупреждение), по желанию
   параллельный UDP-поток на порт телеметрии этого ПК, проверка потока
   UDP-телеметрии, байты в линию RS-485. Под лавиной пакетов программа
   ограничивает разбор датаграмм и вывод в журнал (в журнале появится строка
   «в журнал не вошло K кадров»), счётчики остаются точными. Вкладка **«Приёмка»** — автоматическая
   приёмочная проверка PS с отчётом.

Во время серии калибровки через PS ручные команды заблокированы.
