# Установка S2VNA и подключение к программе

## Роль S2VNA (политика DOC-POL-001)

**S2VNA = SCPI-драйвер** для прибора **C1220/C2220**. Программа является TCP/SCPI-клиентом S2VNA и подключается по явному нажатию кнопки проверки или измерения.

Если S2VNA установлена на этом же ПК, программа запускает её сама (решение от 2026-10-16):

- при нажатии **«Проверить связь»** или кнопки подключения и измерения программа проверяет порт Socket Server на `127.0.0.1`;
- порт свободен — запускает `S2VNA.exe /visible:off /SocketServer:on /SocketPort:<порт>` (для **S2VNA Demo C2220** ещё `/simulate:on`) и ждёт Socket Server до 60 с;
- окно S2VNA не появляется; вернуть его можно кнопкой **«Показать окно S2VNA»** (`SYST:SHOW`), убрать — той же кнопкой (`SYST:HIDE`);
- при выходе программа закрывает только свою копию S2VNA командой `SYST:TERM`; S2VNA, запущенную вручную, она не закрывает;
- файлы настроек S2VNA программа не меняет; ключи — из РЭ S2VNA ч. 2, стр. 343.

Путь к `S2VNA.exe` задаётся в настройках подключения (по умолчанию `C:/VNA/S2VNA/S2VNA.exe`). Снимите флажок **«Запускать S2VNA скрыто»**, чтобы работать по-старому, с S2VNA, запущенной оператором. Для S2VNA на другом компьютере автозапуск не используется.

Прямой COM/USB к C2220 **без** S2VNA не поддерживается и не будет: протокол USB производитель не публикует, а лицензия ПЛАНАР (п. 1.5, 5.2) запрещает его восстанавливать.

## Что нельзя поставить автоматически

**S2VNA** (ПО ПЛАНАР для C2220) **нет в winget/Chocolatey** и не лежит в репозитории: это ПО производителя с диска прибора / личного кабинета / поставки. Скачать и поставить его должен инженер стенда.

Сайт: [planarchel.ru](https://planarchel.ru/) · поддержка: `welcome@planarchel.ru`, 8 (800) 222-12-11.  
Документация в репозитории: `Planar_documentation/`, контракт SCPI: `docs/contracts/vna-c2220-scpi.md`.

## Порядок на стенде

1. Установить **S2VNA** с носителя ПЛАНАР.
2. Подключить **C1220/C2220** по USB.
3. Запустить AFAR RX Calibration Studio, выбрать **C2220 Socket (SCPI)**, адрес `127.0.0.1`, порт `5025`, проверить путь к S2VNA и нажать **«Проверить связь»** либо кнопку подключения и измерения. Программа сама запустит S2VNA скрыто. Если флажок автозапуска снят или S2VNA на другом ПК, запустите S2VNA вручную и включите в ней **Socket Server** на том же порту.
5. После ответа `*IDN?` верхняя полоса покажет **«Источник: живой VNA»**.
6. Для пассивного двухпортового устройства выбрать режим **«Двухпортовое устройство»**. Для перебора кодов — **«Калибровка канала 64×64»**, затем в мастере выбрать короткую проверку, один канал 1…16 на полной сетке 64×64 или все 16 каналов.
7. Калибровка, измерение и экспорт выполняются **из AFAR** при работающем SCPI-сервере.

Альтернатива: **C2220 COM (SCPI)** + имя порта (`COM3` …) — тоже через SCPI-сервер S2VNA.

## Что уже в программе

| Режим | Когда |
|-------|--------|
| **Имитатор** | Без прибора (разработка, CI) |
| **C2220 Socket (SCPI)** | Живой C2220 через TCP → SCPI-сервер S2VNA |
| **C2220 COM (SCPI)** | Живой C2220 через COM → SCPI-сервер S2VNA |
| **S2VNA Demo C2220 (Socket)** | S2VNA Demo Mode без прибора через тот же SCPI-драйвер |

Контроллер изделия пока **DutSimulator / Stub** — до протокола т. 14 ТЗ.

### Демо-режим S2VNA без прибора

Выберите в Studio **S2VNA Demo C2220 (Socket)** и нажмите **«Проверить связь»**.
Программа запустит S2VNA скрыто с ключом `/simulate:on`. Модель для Demo Mode
(C2220) выбирается в самой S2VNA один раз, через **«Показать окно S2VNA»**. При
ручном запуске включите в S2VNA Demo Mode и Socket Server сами. Studio
проверяет `*IDN?`. Успешный Demo
Mode определяется по модели C2220 и пустому серийному номеру. После подключения доступны настройки свипа, графики
S11/S21/S12/S22, Touchstone и PDF-отчёт.

При переключении между Demo и прибором программа перезапускает свою копию S2VNA; S2VNA, запущенную вручную, перезапускает оператор. Демо-данные имитируют заранее записанное устройство и
**не являются измерениями реального анализатора или метрологическими результатами**;
Studio явно указывает это в верхнем бейдже, Touchstone и PDF.

Описание режима производителя: [ПЛАНАР — «Демонстрационный режим»](https://planarchel.ru/instruction/s2vna/demo-mode.html).

## Что на графиках в AFAR (оператору)

S2VNA используется только как SCPI-сервер: вручную выбирать в ней S11/S21/S12/S22 и диапазон не требуется. Частота, точки, ПЧ и мощность задаются в нашей программе. Диапазон можно вводить как начальную/конечную либо центральную частоту/полосу. Кнопка **«Подключить C2220 и измерить всё»** проверяет связь, применяет настройки, измеряет S11/S21/S12/S22 и рассчитывает КСВ-1/КСВ-2. Кнопка **«Применить настройки и измерить всё»** повторяет измерение без ручной работы в S2VNA.

После успешного полного измерения заполните поля изделия и оператора, затем нажмите **«Сохранить .s2p + PDF-отчёт»** и выберите базовое имя. Программа сохранит рядом два файла: совместимый Touchstone `.s2p` и шестистраничный PDF-отчёт с титульным листом, отдельной страницей S11/S21/S12/S22 и итогом. Для каждой трассы приводятся графики модуля и unwrap-фазы, MIN/MAX/AVG, параметры свипа и установленные оператором маркеры; для S11/S22 дополнительно строится график КСВН. Оба файла создаются из одного уже полученного снимка — прибор повторно не опрашивается. Если кнопка недоступна, полного согласованного набора S11/S21/S12/S22 ещё нет.

Поле усреднения пока зафиксировано на 1. Оно будет разблокировано только после проверки точной SCPI-команды на установленной версии S2VNA/C2220; остальные настройки применяются и считываются обратно с прибора.

Для построения КСВН нажмите **«Измерить все S-параметры и КСВН»**, затем выберите **«КСВН-1»** (расчёт по S11) или **«КСВН-2»** (по S22). Обе трассы КСВН можно наложить или разнести по отдельным окнам; маркеры и выражения `M1.VSWR1` / `M1.VSWR2` доступны в терминале. При |Γ| ≥ 1 результат отображается как бесконечность.

Единица справа относится непосредственно к введённому числу: частоту 1,160 ГГц задавайте как **1160 МГц** либо **1,160 ГГц**, но не как 1160 ГГц. Если начальная частота не меньше конечной, программа не запускает некорректный свип и сохраняет на экране последний корректный график.

**LUT** смотрите после Complete: этапы **5 Прямая LUT** / **6 Обратная LUT** (сводка + файл), ячейки вкладки **«Матрица кодов»**, пути — вкладка **«Форматы данных»**.

**Калибровка ВАЦ** (однопортовая OSL / двухпортовая SOLT) управляется из **AFAR** по SCPI (`calibrate_one_port` / `calibrate_two_port`, контракт `docs/contracts/vna-c2220-scpi.md` § 3–4). **S2VNA** — SCPI-сервер и связь с C2220.

Бейдж **«Источник: имитатор (не метрология стенда)»** — программный VNA/DUT, не стендовые измерения. **«Источник: живой VNA»** — реальный **C2220** через **C2220 Socket/COM (SCPI)** после успешной «Проверить связь».

Сетка и деления осей (**f**, дБ / °) — ориентир по частоте и уровню, не метрологическая шкала прибора.

## Уже установлено для сборки (этот ПК)

- MinGW 13 + Qt 6.8.3 `mingw_64`
- CMake, Catch2 (FetchContent)

Если Qt не в `PATH` при запуске exe:

```bat
set PATH=C:\Qt\6.8.3\mingw_64\bin;C:\Qt\Tools\mingw1310_64\bin;%PATH%
build\src\AfarRxCalibrationStudio.exe
```
