# Установка S2VNA и подключение к программе

## Что нельзя поставить автоматически

**S2VNA** (ПО ПЛАНАР для C1220/C2220) **нет в winget/Chocolatey** и не лежит в репозитории: это ПО производителя с диска прибора / личного кабинета / поставки. Скачать и поставить его должен инженер стенда.

Сайт: [planarchel.ru](https://planarchel.ru/) · поддержка: `welcome@planarchel.ru`, 8 (800) 222-12-11.  
Документация в репозитории: `Planar_documentation/`, контракт SCPI: `docs/contracts/vna-c2220-scpi.md`.

## Порядок на стенде

1. Установить **S2VNA** с носителя ПЛАНАР.
2. Подключить **C1220 или C2220**, запустить S2VNA, дождаться связи с прибором.
3. В S2VNA: **System → Misc Setup → Network Remote Control** — включить **Socket Server**, порт обычно **5025**.
4. В AFAR RX Calibration Studio (верхняя полоса):
   - режим **S2VNA Socket**;
   - Host `127.0.0.1` (если S2VNA на этом ПК) или IP ПК со S2VNA;
   - Port `5025`;
   - кнопка **«Проверить связь»** → должен прийти `*IDN?` с `C1220` или `C2220`.
5. Для фильтра: выполнить калибровку в S2VNA либо пошагово на этапе **«2 Калибровка VNA»**, открыть **«4 S-параметры / фильтр»**, выбрать S11/S21/S12/S22 и единицы Гц/кГц/МГц/ГГц.
6. Сначала нажать **«Измерить выбранный S-параметр»**, проверить график, затем отдельно **«Сохранить последнее измерение в CSV»**.

Зелёное **«S-параметры: ГОТОВО»** означает, что VNA доступен для одиночных S11/S21/S12/S22. Жёлтый **«Контроллер серии: ИМИТАТОР»** относится только к автоматическому перебору кодов АФАР и не мешает одиночному измерению фильтра. Нижняя **«Старт серии АФАР»** не запускает одиночный свип: до прохождения мастера она показывает пояснение. На графике колесо мыши меняет масштаб по частоте, перетаскивание левой кнопкой прокручивает увеличенный диапазон, двойной щелчок и кнопка **«Показать весь диапазон»** сбрасывают вид.

Полная двухпортовая SOLT требует OPEN, SHORT и LOAD для каждого порта, затем THRU. Комплект мер выбирается в S2VNA до запуска процедуры; программа его не изменяет.

## Что уже в программе

| Режим | Когда |
|-------|--------|
| **Имитатор** | Без прибора (разработка, CI) |
| **S2VNA Socket** | Живой C1220/C2220 через TCP |

Контроллер изделия пока **DutSimulator / Stub** — до протокола т. 14 ТЗ.

Одиночный свип фильтра не использует контроллер изделия и оркестратор серии АФАР. Программа не выполняет `SYST:PRES` и не создаёт калибровку: активная коррекция S2VNA сохраняется, а `CALC:DATA:SDAT?` читает скорректированные комплексные S21.

## Уже установлено для сборки (этот ПК)

- MinGW 13 + Qt 6.8.3 `mingw_64`
- CMake, Catch2 (FetchContent)

Если Qt не в `PATH` при запуске exe:

```bat
set PATH=C:\Qt\6.8.3\mingw_64\bin;C:\Qt\Tools\mingw1310_64\bin;%PATH%
build\src\AfarRxCalibrationStudio.exe
```
