# Установка S2VNA и подключение к программе

## Роль S2VNA (политика DOC-POL-001)

**S2VNA = SCPI-сервер** для прибора **C2220**. Калибровка ВАЦ и измерения S-параметров выполняются из **AFAR RX Calibration Studio** по SCPI; S2VNA на ПК нужна как процесс удалённого управления (Socket/COM), а не как место ручной калибровки оператором.

Прямой COM/USB к C2220 **без** S2VNA в v1 не поддерживается (нужен новый источник команд и правка `docs/contracts/vna-c2220-scpi.md`).

## Что нельзя поставить автоматически

**S2VNA** (ПО ПЛАНАР для C2220) **нет в winget/Chocolatey** и не лежит в репозитории: это ПО производителя с диска прибора / личного кабинета / поставки. Скачать и поставить его должен инженер стенда.

Сайт: [planarchel.ru](https://planarchel.ru/) · поддержка: `welcome@planarchel.ru`, 8 (800) 222-12-11.  
Документация в репозитории: `Planar_documentation/`, контракт SCPI: `docs/contracts/vna-c2220-scpi.md`.

## Порядок на стенде

1. Установить **S2VNA** с носителя ПЛАНАР.
2. Подключить **C2220**, запустить S2VNA, дождаться связи с прибором.
3. В S2VNA: **System → Misc Setup → Network Remote Control** — включить **Socket Server**, порт обычно **5025**.
4. В AFAR RX Calibration Studio (верхняя полоса):
   - режим **C2220 Socket (SCPI)** (нужен запущенный SCPI-сервер S2VNA);
   - Host `127.0.0.1` (если S2VNA на этом ПК) или IP ПК со S2VNA;
   - Port `5025`;
   - кнопка **«Проверить связь»** → должен прийти полный `*IDN?` с моделью `C2220` (manufacturer, model, serial, firmware).
5. Мастер запуска → калибровка/серия **из AFAR** (при работающем SCPI-сервере).

Альтернатива: **C2220 COM (SCPI)** + имя порта (`COM3` …) — тоже через SCPI-сервер S2VNA.

## Что уже в программе

| Режим | Когда |
|-------|--------|
| **Имитатор** | Без прибора (разработка, CI) |
| **C2220 Socket (SCPI)** | Живой C2220 через TCP → SCPI-сервер S2VNA |
| **C2220 COM (SCPI)** | Живой C2220 через COM → SCPI-сервер S2VNA |

Контроллер изделия пока **DutSimulator / Stub** — до протокола т. 14 ТЗ.

## Что на графиках в AFAR (оператору)

S2VNA используется только как SCPI-сервер: вручную выбирать в ней S11/S21/S12/S22 и диапазон не требуется. Частота, точки, ПЧ и мощность задаются на этапе **«4 Перебор кодов»** нашей программы. Кнопка **«Подключить C2220 и измерить всё»** проверяет связь, применяет эти настройки, измеряет S11/S21/S12/S22 и рассчитывает КСВ-1/КСВ-2. Кнопка **«Применить настройки и измерить всё»** повторяет измерение без ручной работы в S2VNA.

Для построения КСВН нажмите **«Измерить все S-параметры и КСВН»**, затем выберите **«КСВН-1»** (расчёт по S11) или **«КСВН-2»** (по S22). Обе трассы КСВН можно наложить или разнести по отдельным окнам; маркеры и выражения `M1.VSWR1` / `M1.VSWR2` доступны в терминале. При |Γ| ≥ 1 результат отображается как бесконечность.

Единица справа относится непосредственно к введённому числу: частоту 1,160 ГГц задавайте как **1160 МГц** либо **1,160 ГГц**, но не как 1160 ГГц. Если начальная частота не меньше конечной, программа не запускает некорректный свип и сохраняет на экране последний корректный график.

**LUT** смотрите после Complete: этапы **5 Прямая LUT** / **6 Обратная LUT** (сводка + файл), ячейки вкладки **«Матрица кодов»**, пути — вкладка **«Форматы данных»**.

**Калибровка ВАЦ** (однопортовая OSL / двухпортовая SOLT) управляется из **AFAR** по SCPI (`calibrate_one_port` / `calibrate_two_port`, контракт `docs/contracts/vna-c2220-scpi.md` § 3–4). **S2VNA** — SCPI-сервер и связь с C2220.

Бейдж **«Источник: имитатор (не метрология стенда)»** — программный VNA/DUT, не стендовые измерения. **«Источник: живой VNA»** — реальный **C2220** через **C2220 Socket/COM (SCPI)** после успешной «Проверить связь».

Сетка и деления осей (**f**, дБ / °) — ориентир по частоте и уровню, не метрологическая шкала прибора.

## Уже установлено для сборки (этот ПК)

- MinGW 13 + Qt 6.8.3 `mingw_64`
- CMake, Catch2 (FetchContent)

Если Qt не в `PATH` при запуске exe:

```bat
set PATH=C:\Qt\6.8.3\mingw_64\bin;C:\Qt\Tools\mingw1310_64\bin;%PATH%
build\src\AfarRxCalibrationStudio.exe
```
