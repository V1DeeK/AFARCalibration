# План: свип ~1296 МГц и S-параметры C2220 (проверка стенда)

Дата: 2026-09-24.  
Контекст: оператор хочет запустить AFAR RX Calibration Studio на живом C2220 (S2VNA SCPI), выставить среднюю частоту **1296 МГц**, шаг **1 МГц**, ПЧ **1 кГц**, смотреть графики; формулировки «полоса 100» и «в полосе 40 МГц» неоднозначны; запрос «все 4» (S11/S12/S21/S22).  
Опора: `docs/contracts/vna-c2220-scpi.md`, `docs/contracts/cpp-interfaces.md`, `docs/contracts/data-formats.md`, `include/afar/IVna.h`, `include/afar/SweepTypes.h`, `src/vna/C2220Vna.*`, `src/sim/VnaSimulator.*`, `src/data/RunConfig.*`, `src/data/RawS21Store.*`, `src/measure/MeasurementOrchestrator.*`, `src/ui/MeasureTab.*`, `src/ui/S21PlotWidget.*`, `examples/run-config.example.json`.  
Код в этой задаче **не пишется** — только план.

| Слой | Состояние |
|------|-----------|
| SCPI-контракт | `CALC:PAR:DEF S21` — **только S21**; прибор умеет S11/S12/S22, драйвер их **не задаёт** |

**Рабочая гипотеза частот (до ответа на уточнение №1)**

Если «в полосе 40 МГц» = span вокруг центра 1296 МГц, шаг 1 МГц, IFBW = 1 кГц:

| Параметр | Значение |
|----------|----------|

«Полоса 100» **не** заложена в гипотезу — см. «Требует уточнения».

## Цель

Дать оператору проверяемый путь: (A) быстро снять свип S21 на C2220 около 1296 МГц с нужными f_start/f_stop/points/IFBW и увидеть график в Studio; (B) при подтверждённой потребности — расширить продукт до четырёх S-параметров без обхода закрытого SCPI-контракта.

## Критерий готовности

### Блок A

- В рабочем `run-config` (локальный профиль стенда, **не** боевой IP в git) и/или в UI после загрузки профиля: `f_start`/`f_stop`/`points`/`ifbw` соответствуют согласованным числам (гипотеза выше или уточнённые).
- На живом C2220: `*IDN?` проходит; `configure` выставляет STAR/STOP/POIN/BAND; один `measure_s21` даёт 41 (или N) конечных комплексных точек; ось частот совпадает с ожидаемым шагом ~1 МГц.
- Вкладка измерения рисует \|S21\| и фазу по этому свипу (`S21PlotWidget`).
- `vna.s_parameter` остаётся `"S21"`; закрытый SCPI **не** расширен.
- Сборка и `ctest` зелёные; фикстуры 4.9–6 ГГц для LUT/серии AFAR **не ломаются** (отдельный профиль проверки ≠ смена единственного примера без пометки).

### Блок B (не блокирует приёмку A)

- Контракты явно разрешают S11/S12/S21/S22 (или согласованное подмножество) и описывают SCPI (в т.ч. выбор параметра / трасс).
- `IVna` + `C2220Vna` + `VnaSimulator` умеют измерить выбранный параметр (или все четыре по явной политике).
- Сырьё/графики/экспорт согласованы с выбранной политикой хранения; тесты драйвера покрывают смену `CALC:PAR:DEF`.
- Критерии уточняются ответами в «Требует уточнения» (особенно №2: LUT vs только проверка стенда).

## Риски

- Смена дефолтов UI на 1.276–1.316 ГГц «для всех» сломает привычный сценарий калибровки AFAR 4.9–6 ГГц и введёт оператора в заблуждение (см. №3).
- Расширение `IVna`/`ComplexSweep` без правки DOC-003 нарушает правило «посимвольно с т. 8.3».
- Четыре параметра в одном TRIG могут потребовать несколько трасс/каналов SCPI — вне текущей таблицы; без сверки S2VNA легко выдумать запрещённые команды.
- Version bump `RawS21Store` затронет манифест, CSV, Parquet, тесты LUT — высокий объём при «все 4 в серии».
- IFBW «100» vs «1000»: неверный BAND даст другой шум/время свипа; «полоса 100» как span 100 МГц меняет points (101 при шаге 1 МГц).
