# Итог оркестрации: AFAR этап 1, волны 0–10

Дата: 2026-09-22  
План: [`docs/plans/2026-09-22-afar-stage1.md`](../plans/2026-09-22-afar-stage1.md)  
Продукт: AFAR RX Calibration Studio (`AfarRxCalibrationStudio`)

## Краткий вердикт

Волны 0–10 закрыты на имитаторах и stub: каркас CMake/Qt, контракты, ядро серии, хранилище AFARH5/AFARPQ, GUI, драйвер C2220 (Socket+COM), `ctest` 14/14 в компактном режиме. Приёмка AT-01…AT-11 подтверждена без живого стенда. AT-12…AT-14, установщик, реальный DUT и системные libhdf5/Arrow — вне этого контура.

## Закрыто (AT-01…AT-11)

Приёмка на **имитаторах** (`VnaSimulator` / `DutSimulator`) и **TCP-stub** SCPI; реальный C2220 и изделие не требовались.

| AT | Как закрыто | CTest / артефакт |
|----|-------------|------------------|
| AT-01 | Идентификация / отказ чужой модели на имитаторе; драйвер `C2220Vna` через Socket и локальный SCPI-stub (`*IDN?`, проверка direct access) | `simulators`, `c2220_driver` |
| AT-02 | Разбор и валидация `run-config` + CSV аттенюатора | `run_config` |
| AT-03 | Короткий полный цикл оркестратора | `probe_run` |
| AT-04 | Компактная полная сетка в CI (16×4×4×11); полный 65 536 — опционально через `AFAR_RUN_AT04` | `full_sim_run` |
| AT-05 | Пауза / продолжение без порчи completed-слотов | `pause_resume` |
| AT-06 | Восстановление после «аварии» процесса | `crash_recovery` |
| AT-07 / AT-08 | Тайм-аут / обрыв VNA; отказ подтверждения DUT | `faults` |
| AT-09 | Нормировка, фаза, прямая и обратная LUT | `lut_math` |
| AT-10 | Флаги QC | `quality_gates` |
| AT-11 | Экспорт LUT (AFARPQ), PDF, манифест SHA-256, reopen | `export_manifest` |

AT-11 также вызывается из `MeasurementOrchestrator::finalizeExports` при переходе в Complete (Finalizing), а не только из unit-теста экспорта; сбой remanifest после Complete → Error.

**GUI, волна 8:** графики S21 через `S21PlotWidget` (QPainter, ≤5 Гц), ETA по скорости прогона, повтор ячеек FR-18 из матрицы кодов.

Дополнительно: `smoke`, `hdf5_store` (AFARH5), `lut_perf` (замер времени LUT без жёсткого NFR-03 gate в CI).

Полный объём AT-04 / LUT:

```bat
set AFAR_RUN_AT04=1
build\tests\test_full_sim_run.exe "[full]"
build\tests\test_lut_perf.exe "[full]"
```

## Отложено

| Тема | Почему не в волнах 0–10 |
|------|-------------------------|
| **AT-12** | 24-часовой прогон / рост памяти — отдельная программа испытаний на эталонном ПК |
| **AT-13** | Реальный THRU / калибровка ВАЦ на стенде |
| **AT-14** | Измерения на изделии (каналы/коды по методике заказчика) |
| **Установщик Windows, SBOM** | Не входят в скелет и имитаторную приёмку |
| **Реальный стенд** | Нужны боевой IP/профиль, живой C2220, сверка SCPI с установленной S2VNA |
| **Системные libhdf5 / Apache Arrow** | Сознательно не тянулись; канон этапа 1 — AFARH5 и AFARPQ (см. контракт форматов §14–15) |
| **Боевой драйвер DUT** | Протокол контроллера и данные т. 14 не переданы → `StubDutController` без COM/TCP изделия |

## Решения по стеку (подтверждены при старте оркестрации)

| Выбор | Решение |
|-------|---------|
| Тесты | **Catch2** v3.7.1 (FetchContent), не GoogleTest |
| Компилятор / генератор | **MinGW 13** + `MinGW Makefiles` (вместе с Qt mingw_64); MSVC/Ninja не переключались |
| GUI | **Qt 6** (на машине 6.8.3 `mingw_64`); Widgets; железо только через `afar_measure` |
| COM C2220 | **В первой поставке**: `ScpiComTransport` рядом с Socket, без смешения в одном классе |

Связанные следствия: `-O2` вместо `-O3` на MinGW 13 (ICE); предупреждения как ошибки; GUI по умолчанию на имитаторах (`src/app/main.cpp` / `MeasureWorker`).

## Карта модулей после волн

- `afar_measure` — автомат, скан, оркестратор  
- `afar_vna` — Socket + COM + `C2220Vna`  
- `afar_report` — AFARPQ, манифест, PDF  
- `afar_sim` / `afar_dut` — имитаторы и stub DUT  
- `afar_data` — конфиг, каталог серии, AFARH5  

Подробности сборки, список `ctest` и запуск GUI — в корневом [`README.md`](../../README.md).

## Что остаётся инженеру на стенде

1. Сверить SCPI с фактической версией S2VNA.  
2. Прогнать AT-01 на живом C2220 (Socket и при необходимости COM).  
3. Получить данные т. 14 (протокол DUT, пределы, калибровка, пороги) и заменить stub.  
4. Запланировать AT-12…AT-14 и установщик отдельным контуром.
