## Критерии по ТЗ

### AT-09 — прямая LUT, допуск \(10^{-10}\)

| Критерий | Статус | Как проверено |
|----------|--------|---------------|
| Нормировка \(\tilde S = S/R\); нулевой/неконечный R → invalid, без «тихого» NaN в LUT | ✅ | `lut_math`: normalize + DirectLut |
| Модуль / ослабление дБ, `wrap180`, unwrap vs эталон double, \(\lvert\Delta\rvert < 10^{-10}\) | ✅ | `lut_math`, допуск `kTol = 1e-10` |
| Поля прямой LUT (комплекс, mag, phase unwrap, drift, repeatability, valid) | ✅ | `build_direct_lut_entry` + тест полей |
| Выбор обратной LUT по минимуму \(J\) (формула 7), без монотонности/линейности | ✅ | `inverse_cost` / `select_inverse_codes` |
| Эталонный набор заказчика (т. 14 п. 8) вместо чистой синтетики | ❌ | Набора нет; только синтетический double |

### AT-10 — обратная LUT / QC

| Критерий | Статус | Как проверено |
|----------|--------|---------------|
| FR-16: NaN/Inf, overload, дрейф, повторяемость, код/тайм-аут/длина → `valid=false` | ✅ | `quality_gates` + запись слота в оркестраторе |
| FR-17 стартовые пороги (1,0° / 2,8125° / 0,10 дБ / 1,0°) как параметры ПО | ✅ | дефолты `QualityThresholds` + поля `limits` в run-config |
| `valid=false` не выбирается при наличии пригодного (FR-15) | ✅ | `select_inverse_codes` + тесты AT-09/AT-10 |
| Остаток фазы обратной LUT выше FR-17 → `valid=false` в отчёте | ✅ | применено в `buildInverseLutFromDirect` (ранее функция была, но не вызывалась) |
| Утверждённые метрологом пороги / живой QC на стенде | ❌ | вне контура AT09-11-001 |

### AT-11 — reopen, SHA-256, valid

| Критерий | Статус | Как проверено |
|----------|--------|---------------|
| Каталог серии: LUT Parquet (AFARPQ), PDF, `manifest.sha256` | ✅ | `export_manifest` + Finalizing |
| Повторное открытие LUT; число `valid` совпадает с PDF | ✅ | reopen в `finalizeExports` + тест |
| SHA-256 каждого файла; размеры; `verifyManifest` | ✅ | тест + гейт после `writeManifest` перед Complete |
| Сбой экспорта → Error, не «успех с битыми файлами» | ✅ | `EXPORT_FAIL` → Error |
| Независимый скрипт приёмки / эталонная серия на железе | ❌ | нет; только CTest на имитаторе |

Легенда: ✅ закрыто на текущем контуре · ⚠ частично / с оговоркой · ❌ не закрыто (внешняя зависимость или стенд).

## Остаточные gaps

1. **Эталон заказчика (т. 14 п. 8)** — без него AT-09 формально только на синтетике; метрологическая сверка LUT с эталоном невозможна.
2. **Живой стенд** — AT-09…11 не прогонялись на C2220 + реальном DUT; имитатор не заменяет аппаратную приёмку.
3. **Повторяемость в прямой LUT из серии** — в слоте один свип, `repeatability_from_attempts({})` даёт NaN (история attempt только в журнале); для AT-10 gate на записи это терпимо, но оценка repeatability в Parquet из серии пока пустая.
4. **Настоящий Parquet/HDF5** — AFARPQ/AFARH5 суррогаты этапа 1; смена на libhdf5/Arrow — отдельный объём.
