# Безопасность и целостность данных

## Ответы прибора

Любой ответ S2VNA — недоверенный. До использования проверяем: число точек
против оси частот, конечность чисел, флаг перегрузки, очередь ошибок
(`SYST:ERR?`). Битый ответ — ошибка измерения с повтором по профилю, а не
падение и не тихая запись в серию.

```cpp
// ❌ плохо — размер пришёл из ответа прибора
std::vector<std::complex<double>> s21(values.size() / 2);

// ✅ хорошо
if (values.size() != 2 * sweep.points) throw VnaProtocolError(...);
```

## Команды оборудованию

- Ни одной SCPI-записи при невалидном `SweepConfig`: проверка до I/O.
- Только команды из `docs/contracts/vna-c2220-scpi.md`.
- Команды контроллера изделия не выдумываются; при отказе — `set_safe_state`.

## Данные серии

- Запись атомарная: временный файл → commit/rename. Completed-слоты не
  перезаписываются.
- Все итоговые файлы входят в `manifest.sha256`.
- Пути из конфигурации не выходят за каталог серии.

## Секреты

- Боевые IP стенда и пароли не попадают в исходники, `examples/`, тесты и
  логи.
