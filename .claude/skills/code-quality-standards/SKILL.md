# Стандарты качества

Чеклист для `reviewer`. Стиль языка этого репозитория — в правиле
`cpp-qt-style`; здесь — что считать дефектом на ревью.

## Корректность

- Границы: пустой контейнер, нулевая и максимальная длина, деление на ноль.
- Указатели: нет разыменования без проверки, нет висящих после `deleteLater`.
- Новый `.cpp`/`.h` без строки в `CMakeLists.txt` — это несобираемый файл.

## Владение и потоки

- У `QObject` есть родитель или умный указатель. `new` без хозяина — дефект.
- В GUI-потоке нет `waitFor*`, синхронного разбора большого буфера, ожидания
  сокета.
- Связи только через указатель на член: `connect(s, &T::sig, this, &T::slot)`.

## Ошибки и вход

- Ошибка либо возвращается вызывающему, либо пишется в `qWarning` с контекстом.
- Пустой `catch`, проглоченный код возврата, `QSKIP` в тесте «чтобы зеленело» —
  критично.
- Данные с сети проверяются до использования: длина, диапазон, версия схемы.

## Диф

- Нет переформатирования и переименований вне задачи.
- Строки интерфейса — на языке продукта, без транслита.
- Комментарий только там, где код сам себя не объясняет.

Замечание на ревью: место (`файл:строка`) + что не так + как чинить.
Без места это не замечание, а мнение.
